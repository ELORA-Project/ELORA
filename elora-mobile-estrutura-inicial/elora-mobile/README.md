# ELORA
Aplicativo mobile de monitoramento ambiental, análise preventiva de riscos e orientações personalizadas.

## Tecnologias
- Flutter / Dart

## Estrutura
- `lib/screens/`: telas
- `lib/widgets/`: componentes reutilizáveis
- `lib/models/`: modelos de dados
- `lib/services/`: integrações e acesso a dados
- `lib/theme/`: cores, tipografia e tema
- `lib/routes/`: navegação
- `assets/`: imagens, ícones e fontes
- `test/`: testes

## Executar
1. Instale e configure o Flutter.
2. Execute `flutter pub get`.
3. Execute `flutter run`.

## Git
Trabalhe em branches por funcionalidade e integre por Pull Request. Não envie senhas, tokens, chaves de API ou arquivos `.env`.
